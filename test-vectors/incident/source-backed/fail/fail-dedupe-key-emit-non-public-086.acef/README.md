# Forged emit-on-non-public incident_dedupe_key (ACEF-086)

A confidential (regulator-only) source-backed incident_report that EMITS the subject-bearing `incident_dedupe_key` on a NON-public record — the forged emit-on-non-public confidentiality violation (§5.5 Q20). The validator raises ACEF-086 (the reserved §5.11 publishability code), NEVER ACEF-022. Omit the key on a non-public record, or publish the record.

**Expected code(s):** ACEF-086
